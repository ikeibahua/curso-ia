# Lección 09 — Anatomía de un agente

**Bloque 3 · Agentes** · Duración estimada: 75 min · Requisitos: Lecciones 03 y 08

## Objetivos
- Distinguir un chat de un agente.
- Entender el bucle observar–decidir–actuar.
- Ver cómo un modelo pide ejecutar herramientas.

## Contenido a cubrir
- Bucle del agente; llamada a herramientas (function calling).
- Estado, memoria y contexto; planificación; supervisión humana.
- Cuándo un agente es mala idea; coste y errores acumulados.

## Interactivo y animación
- Animación paso a paso del bucle con un ejemplo (ordenar archivos).
- Agente de juguete: elegir herramientas y ver qué puede hacer.

## Práctica en su Mac
- Ejecutar un script mínimo de unas 30 líneas, comentado, que implementa el bucle con una herramienta (listar archivos) y leerlo línea a línea.

## Reto final
Añadir una segunda herramienta (p. ej. leer un archivo) con ayuda de un chat o agente.

## Notas para el agente
- Decidir proveedor y modelo del script tras cerrar el tema de suscripciones, o usar un modelo local para coste cero.
- Si se usa API: tope de gasto obligatorio y entorno aislado (venv).
- Aplica la estructura fija de lección, el sello `Verificado` para datos volátiles y las reglas de `AGENTS.md`.
