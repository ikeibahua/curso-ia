# Lección 08 — Terminal II: instalar herramientas y claves

**Bloque 2 · Terminal** · Duración estimada: 75 min · Requisitos: Lección 07

## Objetivos
- Instalar herramientas con Homebrew.
- Entender variables de entorno y PATH.
- Manejar claves de API sin cometer errores de seguridad.
- Leer un script antes de ejecutarlo.

## Contenido a cubrir
- Qué es Homebrew; brew install y upgrade.
- Variables de entorno, PATH, `.zshrc` a nivel introductorio.
- Claves de API: qué son, cómo guardarlas y por qué no compartirlas ni subirlas.
- nano mínimo; curl; qué hace `curl | bash` y cómo leerlo antes.
- Ollama por línea de comandos (opcional).

## Interactivo y animación
- Explicador de comandos por partes.
- Animación de cómo el PATH busca un programa.

## Práctica en su Mac
- Instalar Homebrew con la guía oficial verificada, instalar una herramienta sencilla y crear una variable de entorno de prueba.

## Reto final
Leer un script de instalación de ejemplo, marcar qué hace cada bloque y decidir si lo ejecutaría.

## Notas para el agente
- Verificar el comando oficial de instalación de Homebrew en su web; no copiarlo de memoria.
- Enseñar a verificar la fuente de un instalador.
- Aplica la estructura fija de lección, el sello `Verificado` para datos volátiles y las reglas de `AGENTS.md`.
