# Lección 12 — Agentes de programación y de escritorio I: uso real

**Bloque 3 · Agentes** · Duración estimada: 90 min · Requisitos: Lecciones 08, 09 y 11

## Objetivos
- Saber qué hacen Claude Code, Codex y opencode más allá de programar.
- Trabajar con un agente de forma segura y supervisada.
- Deshacer cambios.

## Contenido a cubrir
- Qué son como categoría; ordenar documentos, procesar datos, escribir scripts, investigar.
- Flujo: pedir → planificar → revisar → aceptar.
- Permisos y modos; trabajar en una carpeta acotada.
- Cómo deshacer: copia previa, Time Machine y git mínimo (init, add, commit, restore) en unos 10 minutos.
- Escribir buenos encargos y verificar resultados.
- Aplicar el criterio de elección de modelo y nivel de esfuerzo de L20.

## Interactivo y animación
- Simulador de sesión con aprobaciones y consecuencias.
- Animación plan → acciones → diferencias.

## Práctica en su Mac
- Tarea acotada: organizar un directorio de prueba tras hacer una copia de seguridad.

## Reto final
Reescribir tres encargos mal formulados.

## Notas para el agente
- El destinatario no tiene plan de pago: usar opencode con modelo gratuito o local, o lo que se decida; verificar disponibilidad y límites actuales.
- Aplica la estructura fija de lección, el sello `Verificado` para datos volátiles y las reglas de `AGENTS.md`.
