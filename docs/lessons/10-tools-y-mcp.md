# Lección 10 — Tools y MCP

**Bloque 3 · Agentes** · Duración estimada: 75 min · Requisitos: Lección 09

## Objetivos
- Entender qué es una herramienta para un modelo.
- Entender el papel de MCP y su diferencia con skills.
- Conectar un servidor MCP sencillo con permisos acotados.

## Contenido a cubrir
- Qué es una tool: nombre, descripción, parámetros; importancia de la descripción.
- MCP como protocolo estándar (analogía con USB-C); clientes y servidores; locales y remotos.
- Tools, skills y MCP: diferencias.
- Permisos y riesgos.
- Anticipar el caso de uso de L21 (MCP para FreeCAD) como ejemplo de herramienta con efectos reales en el mundo físico.

## Interactivo y animación
- Diagrama animado cliente–servidor MCP.
- Diseñador de tools con casos predefinidos.

## Práctica en su Mac
- Conectar un servidor MCP sencillo (p. ej. sistema de archivos) a un cliente compatible y pedir una tarea; revisar qué permisos se concedieron.

## Reto final
Explicar qué pasaría si un servidor MCP tuviera acceso a toda su carpeta personal y cómo lo limitaría.

## Notas para el agente
- Verificar el estado actual de MCP y los servidores de referencia.
- Elegir un cliente compatible con el plan que tenga disponible.
- Aplica la estructura fija de lección, el sello `Verificado` para datos volátiles y las reglas de `AGENTS.md`.
