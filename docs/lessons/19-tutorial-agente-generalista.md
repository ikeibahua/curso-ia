# Lección 19 — Tutorial opcional: montar un agente generalista

**Bloque 4 · Cierre (opcional)** · Duración estimada: 120 min · Requisitos: Lecciones 15 y 16

## Objetivos
- Instalar y configurar un agente generalista de forma segura y aislada.
- Saber apagarlo y desinstalarlo.

## Contenido a cubrir
- Preparar una máquina o contenedor aislado (nunca el Mac de uso diario).
- Instalar el agente elegido siguiendo la documentación oficial vigente.
- Conectar un canal de mensajería con una cuenta dedicada.
- Configurar el modelo (local o API con tope de gasto) y permisos mínimos.
- Primera tarea, memoria y skills; monitorización; apagado de emergencia; desinstalación limpia.

## Interactivo y animación
- Checklist de progreso con persistencia local.
- Arquitectura animada.

## Práctica en su Mac
- Seguimiento completo del tutorial.

## Reto final
Una tarea programada diaria sencilla durante una semana.

## Notas para el agente
- Preguntar a Iker qué máquina se usará y qué agente se elige.
- Verificar cada comando con la documentación vigente.
- Aplica la estructura fija de lección, el sello `Verificado` para datos volátiles y las reglas de `AGENTS.md`.
