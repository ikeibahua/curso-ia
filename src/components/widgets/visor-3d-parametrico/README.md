# Widget: Visor 3D Paramétrico (`visor-3d-parametrico`)

## Propósito
Permite al alumno entender el concepto fundamental de **modelado paramétrico**:
- Una pieza no es un dibujo estático, sino una estructura geométrica vinculada a variables numéricas (ancho, profundidad, altura, diámetro de orificios, número de cavidades).
- Proporciona un visor isométrico 2D/3D ligero en SVG que se actualiza en tiempo real al manipular los controles.
- Ofrece el script Python equivalente para FreeCAD listo para copiar y pegar en la consola del programa.

## Accesibilidad
- Controles de rango con etiquetas `<label>` semánticas.
- Diagnóstico textual claro sobre el grosor mínimo de pared para impresión 3D FDM.
