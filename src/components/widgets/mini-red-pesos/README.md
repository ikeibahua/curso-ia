# Widget: Mini Red Neuronal con Pesos Editables

Demostración interactiva de cómo los parámetros numéricos (pesos $w$) actúan como ponderadores matemáticos en una red neuronal.

## Propósito
Desmitificar el concepto de "parámetro" o "peso" conectándolo con la intuición botánica:
- Dos variables de entrada sensorial (horas de insolación y humedad).
- Dos neuronas intermedias con función de activación ReLU.
- Seis pesos ajustables que modulan la intensidad de las conexiones sinápticas.
- Una neurona de salida sigmoidea que predice la probabilidad de floración.

## Funcionalidades
- Control deslizante en tiempo real de entradas y pesos individuales.
- Presets inmediatos de floración óptima versus estrés por sequía.
- Cálculo determinista instantáneo sin peticiones de red.
- Accesibilidad con etiquetas semánticas y alto contraste.
