# Widget: Similitud Semántica entre Frases

## Propósito
Permite al alumno comparar dos frases y comprobar cómo un modelo mide la cercanía semántica (similitud coseno) entre sus respectivos vectores de embedding.

## Reglas técnicas
- Ofrece datos precalculados de alta fidelidad para uso inmediato sin necesidad de descargar modelos pesados en la carga inicial.
- Incluye ejemplos en español de biología y lenguaje cotidiano, demostrando que frases con palabras diferentes pueden ser muy afines y viceversa.
