# Widget: Línea Temporal de la IA (`linea-temporal-ia`)

## Propósito
Ofrece una perspectiva histórica clara desde el nacimiento de la arquitectura Transformer (2017) hasta los agentes de escritorio con MCP y diseño 3D (2025–2026), explicando para cada hito:
- La innovación técnica subyacente.
- El impacto directo en un usuario común.
- Un paralelismo biológico evolutivo honesto.

## Accesibilidad
- Paginación e hitos mediante botones con etiquetas accesibles y contraste WCAG AA.
- Información estructurada en texto legible con contraste verificado.
