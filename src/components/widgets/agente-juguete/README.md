# Widget: Agente de Juguete (Caja de Herramientas)

Simulador interactivo de orquestación de herramientas para agentes inteligentes.

## Propósito
Permite al estudiante entender que las capacidades de un agente no provienen de un conocimiento infinito en sus pesos, sino de las herramientas que tiene conectadas en su entorno:
- Selección interactiva de herramientas activas (búsqueda web, lectura de ficheros, calculadora, guardado en disco).
- Misiones complejas que exigen encadenar varias herramientas en secuencia.
- Diagnóstico de fallos cuando al agente le falta una herramienta indispensable (bloqueo por incapacidad de acceso físico vs error de cálculo estocástico).

## Funcionalidades
- Conmutadores independientes para 5 herramientas estándar.
- Consola de ejecución que muestra el rastreo paso a paso de las llamadas JSON.
- Retroalimentación pedagógica instantánea.
- Accesibilidad con botones semánticos y alto contraste.
