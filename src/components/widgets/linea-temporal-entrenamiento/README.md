# Widget: Línea Temporal de Entrenamiento

Visualizador interactivo de las etapas de desarrollo y aprendizaje de un Modelo de Lenguaje de Gran Escala (LLM).

## Propósito
Explicar con claridad meridiana la diferencia entre:
1. Preentrenamiento masivo (el modelo salvaje que solo predice tokens).
2. Ajuste Fino Supervisado / SFT (aprender el formato de asistente).
3. Alineamiento mediante Preferencias / RLHF (seguridad, cortesía y filtro de respuestas perjudiciales).
4. Razonamiento guiado por refuerzo (la nueva frontera de modelos tipo o1, o3 y Claude Thinking que razonan antes de hablar).

## Funcionalidades
- Selección intuitiva por pestañas/cinta temporal.
- Desglose de costes, volumen de datos y tiempo de supercómputo.
- Ejemplos comparativos reales de salida del modelo frente a una misma pregunta botánica en cada fase.
- Analogía evolutiva y biológica asociada a cada estadio de desarrollo.
- Diseño accesible y adaptativo para pantallas de escritorio y móviles.
