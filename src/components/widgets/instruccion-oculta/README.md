# Widget: Encuentra la Instrucción Oculta (`instruccion-oculta`)

## Propósito
Enseña de forma visual e intuitiva el vector de ataque más relevante en sistemas de agentes autónomos: la **inyección indirecta de instrucciones** (*indirect prompt injection*).

## Funcionamiento
- Permite alternar entre la visión humana (un documento en PDF o correo con apariencia profesional y limpia) y la visión en crudo del agente (que revela texto oculto o metadatos con órdenes maliciosas).
- Permite comparar el desenlace de la ejecución ante un agente sin límites de privilegios frente a uno confinado con el principio de mínimo privilegio (*least privilege*).

## Accesibilidad
- Alternancia de modos con botones accesibles e indicación clara de estado.
- Código legible con contraste y alternativas textuales.
