# Widget: Checklist de Despliegue con Progreso Local (`checklist-despliegue`)

## Propósito
Guía al alumno paso a paso en la instalación y configuración segura de un agente generalista (Hermes Agent):
- Guarda el estado de progreso en el `localStorage` del navegador para que el usuario no pierda sus avances entre sesiones.
- Desglosa los 7 hitos críticos (entorno aislado, instalación, bot de Telegram, lista blanca de seguridad, configuración de modelo con coste 0€, primera tarea y comprobación del interruptor de parada).

## Accesibilidad
- Formularios semánticos con casillas de verificación accesibles.
- Indicador visual y porcentual de progreso con alternativas textuales.
