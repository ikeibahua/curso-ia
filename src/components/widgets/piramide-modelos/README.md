# Widget: Pirámide de Modelos

Visualizador jerárquico interactivo que separa los 4 niveles conceptuales de la inteligencia artificial moderna:
1. Empresa desarrolladora (OpenAI, Anthropic, Google, Meta...).
2. Herramienta o producto (ChatGPT, Claude.ai, terminal, APIs).
3. Familia y tamaño del modelo (Astra, Opus, Sonnet, Haiku, Llama...).
4. Nivel de esfuerzo de razonamiento (none, low, medium, high, max).

## Propósito
Desarmar de forma intuitiva confusiones cotidianas como "yo uso ChatGPT" sin saber qué modelo concreto responde, y mostrar que el mismo modelo puede estar disponible en distintas herramientas o con distintos niveles de pensamiento.

## Funcionalidades
- Navegación interactiva por cada uno de los 4 niveles.
- Desglose paralelo de ejemplos reales verificados para los 4 ecosistemas principales.
- Cuadros de advertencia con el error de concepto más frecuente en cada escalón.
- Accesibilidad con estados ARIA y colores con contraste garantizado.
