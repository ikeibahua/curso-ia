# Widget: Ficha de Proyecto (`ficha-proyecto`)

## Propósito
Herramienta interactiva para estructurar un proyecto personal de automatización o fabricación física con IA:
- Ofrece 4 plantillas adaptadas al alumno (organizador de fotos, alerta matutina de clima, consultorio RAG local, soporte 3D a medida).
- Permite editar todos los campos clave (objetivo, entradas, salidas, modelo/herramientas, interruptor de apagado).
- Incluye copia directa en Markdown y descarga en local del archivo `PROYECTO.md`.

## Accesibilidad
- Formularios semánticos con etiquetas `<label>` vinculadas.
- Botones de acción directa navegables por teclado.
