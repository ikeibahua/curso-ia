# Widget: Editor Markdown con Vista Previa en Vivo

Editor interactivo en dos paneles para redactar y previsualizar archivos de instrucciones `.md` (Markdown).

## Propósito
Permite al estudiante familiarizarse con la sintaxis de Markdown utilizada universalmente por los agentes inteligentes (`#`, `##`, `**negrita**`, `*cursiva*`, listas, código en línea y citas) y entender por qué es el formato ideal para archivos como `AGENTS.md` o `CLAUDE.md`.

## Funcionalidades
- Edición de texto plano en tiempo real con sincronización visual en el panel derecho.
- Plantillas prediseñadas: `AGENTS.md` para proyectos de botánica y `Nota de campo`.
- Barra de botones con atajos para insertar encabezados, listas y citas.
- Accesibilidad con etiquetas semánticas y alto contraste.
