# Widget: La Mochila de Contexto (Context Engineering)

Simulador interactivo del presupuesto de ventana de contexto (*Context Window*) y tokens para agentes de IA.

## Propósito
Enseñar al alumno a aplicar principios sólidos de ingeniería de contexto:
- Por qué atiborrar al agente de manuales de 40 páginas provoca amnesia en el medio (*Lost in the Middle*) y encarece las consultas.
- Cómo un archivo `AGENTS.md` limpio y conciso (400 tokens) orienta mejor que mil párrafos de relleno.
- La ventaja de las *Skills* modulares cargadas bajo demanda solo cuando la tarea lo requiere.

## Funcionalidades
- Medidor visual del presupuesto de tokens en tiempo real.
- Conmutador interactivo de 7 componentes de contexto típicos.
- Diagnóstico automático de salud del prompt con avisos de saturación.
- Accesibilidad con etiquetas semánticas y contraste AA.
