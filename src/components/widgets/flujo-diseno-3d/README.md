# Widget: Flujo de Diseño 3D (`flujo-diseno-3d`)

## Propósito
Ofrece una guía práctica e interactiva en tres pestañas para el proceso de fabricación aditiva con IA:
1. **El Ciclo en 5 Fases:** medición real con calibre, prompt estructurado, modelo en FreeCAD, exportación a STL/3MF y laminado para impresión 3D.
2. **Checklist de Imprimibilidad:** verificación interactiva de voladizos (regla de los 45°), grosor mínimo de pared, holgura de tolerancia (+0.3 mm), orientación plana y relleno estructural.
3. **Comparativa Tinkercad vs FreeCAD:** contraste entre modelado por bloques CSG y modelado paramétrico con Python y MCP.

## Accesibilidad
- Navegación por pestañas mediante botones accesibles.
- Checklist con elementos `<input type="checkbox">` e indicadores de progreso textuales.
