# Widget: Checklist de Seguridad de Proyecto (`checklist-seguridad-proyecto`)

## Propósito
Proporciona al alumno una lista de control rigurosa antes de poner en marcha o automatizar su proyecto final:
1. Copia de respaldo / instantánea de Git.
2. Aislamiento en carpeta acotada (*sandbox*).
3. Prueba inicial con muestras sintéticas.
4. Límite estricto de presupuesto o coste local 0€.
5. Interruptor de apagado comprobado (*Kill Switch*).
6. Documentación de directrices (`AGENTS.md` / `README.md`).

## Accesibilidad
- Casillas `<input type="checkbox">` accesibles y navegables mediante teclado.
- Etiquetas claras y estados de progreso visuales y textuales.
