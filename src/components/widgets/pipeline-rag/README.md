# Widget: Pipeline RAG Animado (`pipeline-rag`)

## Propósito
Ilustra de forma secuencial y didáctica el flujo completo de Recuperación Aumentada por Generación (RAG):
1. **Documento Fuente:** texto botánico original.
2. **Troceado (Chunking):** partición en unidades semánticas.
3. **Embeddings:** conversión de fragmentos a vectores matemáticos.
4. **Búsqueda por Similitud:** filtrado de fragmentos más próximos a la pregunta formulada.
5. **Generación con Citas:** inyección de los trozos en el contexto y redacción de una respuesta rigurosa con referencia explícita a la fuente.

## Accesibilidad
- Paginación secuencial por pasos con botones accesibles e indicación de estado deshabilitado.
- Contraste de colores verificado conforme a los estándares WCAG AA.
