# Widget: Explicador de Comandos por Partes

Herramienta interactiva de desglose y disección sintáctica de comandos de terminal Unix/macOS.

## Propósito
Desarmar el miedo a comandos aparentemente crípticos (como tuberías de instalación web con `curl`, configuración de variables de entorno con `export` o gestión de paquetes con `brew`) dividiéndolos en fragmentos interactivos seleccionables.

## Funcionalidades
- Selección de tres casos de uso habituales de la lección (instalación de Homebrew, clave de API, instalación de paquete).
- Desglose token a token en píldoras clicables.
- Explicación didáctica de banderas (`-f`, `-s`, `-S`, `-L`) y sustituciones de comando (`$()`).
- Advertencias de seguridad integradas sobre la ejecución de scripts remotos y la protección de claves secretas.
- Cumple con contraste cromático AA y accesibilidad por teclado.
