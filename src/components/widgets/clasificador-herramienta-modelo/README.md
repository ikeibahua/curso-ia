# Widget: Clasificador de Términos (Empresa vs Herramienta vs Modelo)

Mini-juego interactivo de discriminación conceptual.

## Propósito
Permite al estudiante poner a prueba y afianzar la diferencia radical entre:
- Empresa u organización matriz (OpenAI, Anthropic).
- Herramienta o interfaz de acceso (ChatGPT, Claude.ai, Ollama).
- Modelo de red neuronal (Sonnet, Haiku, Opus, Astra).

## Funcionalidades
- Selección accesible mediante botones de opción directa (sin dependencias complejas de drag-and-drop táctil).
- Corrección visual instantánea con explicaciones específicas para cada uno de los 8 términos.
- Marcador de aciertos y botón de reinicio.
- Alto contraste cromático y estados accesibles.
