# Widget: Diagrama Cliente-Servidor MCP

Visualizador interactivo de la arquitectura de comunicación del protocolo abierto Model Context Protocol (MCP).

## Propósito
Explicar el estándar universal de conectividad creado para agentes de inteligencia artificial:
- El Cliente MCP (la aplicación de chat o agente).
- El cable de transporte estandarizado (JSON-RPC sobre stdio o HTTP/SSE).
- Los Servidores MCP modulares e intercambiables (Archivos locales, Bases de datos, FreeCAD 3D, Web).
- Simulación en vivo del descubrimiento dinámico de herramientas (`tools/list`) y de la invocación remota (`tools/call`).

## Funcionalidades
- Selección interactiva entre 4 servidores representativos del curso.
- Simulación de tráfico de red en formato JSON-RPC.
- Accesibilidad y contraste AA.
