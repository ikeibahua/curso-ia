# Widget: Diseñador de Tools (La Importancia de la Descripción)

Simulador didáctico de diseño de especificaciones de herramientas (*Tool Calling*).

## Propósito
Demostrar de forma empírica por qué la descripción en lenguaje natural dentro del esquema JSON de una herramienta es el factor determinante para que un modelo decida activarla o ignorarla:
- Comparativa interactiva entre una descripción vaga e incompleta frente a una descripción técnica rigurosa.
- Pruebas de fuego con consultas botánicas relevantes e irrelevantes.
- Demostración de extracción de parámetros tipados (`string`, `number`).

## Funcionalidades
- Alternancia de calidad de especificación.
- Veredicto inmediato de decisión del LLM con justificación.
- Accesibilidad y contraste AA.
