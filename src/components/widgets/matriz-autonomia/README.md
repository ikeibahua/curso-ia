# Widget: Matriz de Autonomía (`matriz-autonomia`)

## Propósito
Permite al alumno discriminar qué tareas conviene delegar y bajo qué arquitectura:
1. **Agente puntual de terminal:** para operaciones de datos, ordenación de carpetas y código supervisado con red de seguridad.
2. **Agente generalista 24/7:** para monitorización desatendida de clima o toma de notas por mensajería móvil.
3. **Líneas rojas infranqueables:** compras con tarjeta bancaria o suplantación en correspondencia personal.

Incorpora además una advertencia sobre el "goteo silencioso de tokens" (*token bleed*) para evitar sorpresas económicas en ejecuciones continuas.

## Accesibilidad
- Filtros por botones accesibles con estados activos contrastados.
- Etiquetas visuales reforzadas con texto explícito y códigos de color accesibles.
