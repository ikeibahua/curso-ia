# Widget: Comparativa Filtrable (`comparativa-filtrable`)

## Propósito
Permite al alumno contrastar las principales herramientas del ecosistema de agentes para terminal y código (OpenCode, Claude Code, Aider, Goose, Copilot CLI). Ofrece filtros por tipo de licencia, modo de privacidad (local vs nube) y categoría de coste (gratuito 0€ vs suscripción de pago).

## Fuentes y Verificación
- Todos los datos técnicos, comandos de instalación y precios reflejan la documentación oficial de Anthropic, OpenCode y los repositorios correspondientes con fecha de verificación visible.

## Accesibilidad
- Filtros mediante controles `<select>` y `<label>` semánticos.
- Plegado y desplegado de tarjetas accesible mediante teclado y lectores de pantalla.
