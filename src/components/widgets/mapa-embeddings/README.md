# Widget: Mapa de Embeddings 2D y Álgebra Vectorial

## Propósito
Permite al alumno explorar visualmente un espacio semántico bidimensional. Muestra cómo las palabras con significados o funciones afines (especialmente en ecología, botánica y vida cotidiana) se agrupan en regiones próximas (clusters) y cómo funciona la distancia y la suma/resta vectorial.

## Características
- Gráfico interactivo con coordenadas normalizadas.
- Búsqueda de vecinos más cercanos mediante similitud coseno.
- Simulación de álgebra vectorial (ej. analogía rey - hombre + mujer).
- Accesible con teclado y compatible con lectores de pantalla.
